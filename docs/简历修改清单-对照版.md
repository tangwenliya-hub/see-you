## 一、🔴 必改项（6条）

### 1. 求职意向：别写"工程师"，要写"实习生"
- 原文：`求职意向：全栈开发工程师`
- 改为：`求职意向：全栈开发实习生（Java / Vue 方向）`
- 原因：你投的是实习岗，写"工程师"会让对方按正式员工预期衡量，容易被认为不匹配；明确"实习生"定位反而对口。

### 2. 项目1去掉"独立全栈开发"
- 原文：`绪见·情绪记录平台　独立全栈开发`
- 改为：`绪见 · 情绪记录平台　个人全栈练习项目　2026.08 - 至今`
- 原因："独立开发"=暗示全部手写，和 AI 辅助事实冲突，会诱导面试官逐模块追问；"个人练习项目"降低工程深度预期，更安全。

### 3. 职业技能里删掉/改写"单元测试"那句（高危）
- 原文：`掌握 Git 基础操作，接触过 JWT 单元测试，具备基础代码质量意识`
- 改为：`熟悉 Git 常用提交与分支操作；了解 JWT 登录鉴权的基本流程`
- 原因：①"JWT 单元测试"把两件事混在一起，容易被问"你写了哪些测试、测了什么"；②项目里的测试不是你写的，答不上来就露馅。删掉测试表述最稳。

### 4. "经验丰富"自我评价必须改（学生写这个显假）
- 原文第1条：`经验丰富：有丰富的知识体系做基础，能确保文件准确性和完整性`
- 改为：`学习能力：对前后端开发有持续兴趣，能通过官方文档和排错独立解决基础问题，上手快`
- 原因：实习生没有"丰富经验"，这句反而减分；换成岗位更看重的"学习能力/上手快"。

### 5. 补实习关键信息：到岗时间 + 可实习时长（实习岗必看，现在缺失）
- 在求职意向行下方或自我评价末尾加一行：
  `可实习：每周可到岗 5 天，可连续实习 6 个月以上，可尽快到岗（以实际沟通为准）`
- 原因：实习招聘最关心"能不能稳定来、来多久"，简历不写容易被直接刷掉。天数/月数按你真实情况改。

### 6. 项目2核对名称与框架措辞，避免被问穿
- 请先核对项目名是否有错别字（截图疑似"只小宠物商城"，按你真实项目名写全）。
- 原文：`对接 Ruoyi 后端完成联调`
- 建议改为：`对接后端 REST 接口完成前后端联调`
- 原因：RuoYi 是特定后台框架，写上去可能被追问框架结构/权限细节；只说"对接后端接口"即可，既真实又安全。"项目组长"若被问统筹细节，准备一句：负责拆分页面任务、协调进度、汇总联调与修 Bug。

## 二、🟡 建议优化项（6条）

### 7. "Vue3 全家桶"措辞偏大
- 原文：`会使用 Vue3 全家桶、Element Plus、Vite 构建，了解原生 JS、响应式布局……`
- 改为：`熟悉 Vue3 基础开发（组件、响应式、生命周期、路由），使用 Element Plus、Vite 开发页面；了解原生 JS 与响应式布局；能使用 ECharts 实现基础图表展示`
- 原因："全家桶"暗示 router/pinia/vuex 全掌握，你 Pinia 不熟就别用这个词；列具体能力更可信。

### 8. "熟悉 Git 分支管理"降级为常用操作
- 改为：`熟悉 Git 常用命令（add / commit / push / pull / 分支创建与合并）`
- 原因：只会基础提交就别说"熟悉分支管理"，避免被问 rebase、冲突解决细节。

### 9. "可在工具辅助下完成全栈项目开发"改顺、别留歧义
- 原文：`了解 SpringBoot + MySQL，可在工具辅助下完成全栈项目开发`
- 改为：`了解 Spring Boot + MySQL 基础，能完成后端 CRUD 接口与数据库表的基础开发`
- 原因："工具辅助"容易被直接联想成 AI 代写；改成"能做什么"比"靠什么工具做"更专业。

### 10. 给项目1加代码仓库链接（JD 明确"GitHub/项目仓库加分"，你已有 gitee 远程库）
- 在项目1标题右侧加：`代码仓库：gitee.com/TangZaiLiii/a-glimpse-ahead`（按你真实可公开的地址填；不想公开可略过）
- 原因：实习岗有提交记录的仓库比空口描述更有说服力，也能佐证不是纯口头项目。

### 11. 自我评价三条全部换成岗位导向
- 建议替换为（按真实情况微调）：
  1. `学习能力：对 Web 全栈开发兴趣稳定，能查文档、按报错定位并解决基础问题，愿意从 CRUD 和 Bug 修复做起。`
  2. `做事细致：写代码习惯核对接口返回与数据一致性，提交前自测主要流程，减少低级错误。`
  3. `协作与稳定性：沟通直接、责任心强；可保证稳定出勤实习，服从团队安排与代码规范。`
- 原因：原三条（沟通协调/自我管理）是空泛套话，HR 记不住；换成技术相关 + 稳定性更对口。

### 12. 证书与课程补全全称
- `计算机程序设计员（三级证）` → `计算机程序设计员（三级/中级）`；
- 教育背景专业名按真实全称写（不要简写"AI全栈"）；主要课程保留现状即可（覆盖 Java、JS、数据库、Web，和岗位吻合）。
